# Vector Reference Model

Role: `runtime-compatibility`.

Vector references point to SemFS/vector memory outside the repo.

Seed URI pattern:

`semfs://vector/solo-identity-seed/{namespace}/{record_or_index_id}`

Markdown files should say what exists, why it matters, and where to retrieve it. They should not become a hidden dump of private records.

Seed memory starts empty and grows only through policy-governed summaries.
