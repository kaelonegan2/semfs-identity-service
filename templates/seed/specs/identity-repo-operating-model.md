# Identity Repo Operating Model

Role: `guidance`.

This repo is the initialized seed operating identity for a Solo-compatible AI-native identity.

It is portable, runtime-agnostic, and intentionally under-contextualized. A compatible runtime can help it mature by reading the repo, compiling common prep, routing seed agents, validating structured facets, writing safe artifacts, using vector summaries through policy, and gating authority through human review.

The repo is not runtime code.
