# Knowledge Base Lifecycle

Role: `guidance`.

1. Gather common questions from owner input, research, conversations, and feedback.
2. Draft candidate answers.
3. Mark all candidates `draft_pending_owner_review`.
4. Score confidence and risk.
5. Route approval-sensitive items to `human_review`.
6. Treat approved answers as future active knowledge only after registry/policy support exists.

Only approved knowledge can become canonical external-facing guidance.
