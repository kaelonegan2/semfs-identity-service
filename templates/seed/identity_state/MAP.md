# Identity State Map

Role: `authoritative` state traversal map.

`identity_state/` is the runtime-facing state layer for the seed identity. Runtimes come here when they need current status, prompts, registries, route semantics, tool rules, output contracts, lifecycle guidance, memory policy, or capability evolution.

Read first:

1. `lifecycle/current.json`
2. `status/current.json`
3. `profile/current.json`
4. `orchestration/dispatch-map.json`
5. `registries/agents.json`
6. `registries/tools.json`
7. `registries/output-contracts.json`
8. `registries/facet-policy.json`
