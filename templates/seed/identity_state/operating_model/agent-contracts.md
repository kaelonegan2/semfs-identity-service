# Seed Agent Contracts

Role: `guidance`.

Authoritative output contracts live in `identity_state/registries/output-contracts.json`.

Each active seed agent must produce the facet registered in `identity_state/registries/agents.json` and governed by `identity_state/registries/facet-policy.json`.

## Active Contracts

- `owner_onboarding`
- `context_summary`
- `research_plan`
- `knowledge_draft`
- `capability_gap`
- `capability_proposal`
- `human_review`
- `usage_event`
- `closeout`

Future mature contracts are inactive until proposed, approved, evaluated, and activated.
