# Vector Namespaces

Role: `authoritative` seed vector model.

Initial state: no vector memory yet.

The seed identity is ready to use SemFS/vector memory, but it must not pretend memory already exists.

## Initial Allowed Summary Upserts

- owner onboarding summary
- owner-provided identity or business description summary
- research summary draft
- knowledge draft feedback
- capability gap history
- inactive capability proposal summary
- human review summary
- usage event
- conversation closeout summary

## Future-Use Namespaces

Audience memory, preference memory, private operational records, payment history, credential events, and mature workflow records are future-use unless approved and activated.

## Examples

Owner onboarding summary:

`semfs://vector/solo-identity-seed/owner-onboarding-summaries/2026-04-30-initial-focus`

Research summary:

`semfs://vector/solo-identity-seed/research-summary-drafts/initial-domain-research`

Knowledge draft feedback:

`semfs://vector/solo-identity-seed/knowledge-draft-feedback/faq-round-001`

Capability gap history:

`semfs://vector/solo-identity-seed/capability-gap-history/intake-gap-001`
