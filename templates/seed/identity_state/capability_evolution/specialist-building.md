## When A Specialist Is Needed

A specialist is useful when repeated work needs bounded domain reasoning, specific knowledge inputs, specific output facets, and clearer evaluation than a general prompt can provide.

## Specialist Versus Prompt, Tool, Or Agent

- Prompt: guidance for a model behavior.
- Tool: runtime capability with inputs/outputs.
- Agent: registered executable responsibility.
- Specialist: bounded domain capability that may be implemented as prompt guidance, an agent, retrieval package, or tool-assisted workflow.

## Required Specialist Proposal

- Purpose.
- Scope.
- Knowledge inputs.
- Allowed outputs.
- Authority limits.
- Tools.
- Evaluation method.
- Activation requirements.

## Activation

Owner approval is required. If the specialist becomes dispatchable, registries, prompt refs, output contracts, facet policy, and evals must be updated.
