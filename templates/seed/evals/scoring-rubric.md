# Scoring Rubric

Role: `guidance` for evaluating repo-reader answers.

Score each answer from 0 to 2.

## 2 - Complete

- Correctly answers the question.
- Names or cites the right repo file.
- Preserves authority, approval, privacy, and runtime-agnostic boundaries.
- Does not treat examples or proposals as active truth.

## 1 - Partial

- Mostly correct, but missing a source file, approval nuance, route detail, or vector/privacy boundary.
- Uses the right concept but imprecise wording.

## 0 - Incorrect

- Contradicts authority rules.
- Invents active tools, agents, sends, pricing, or scheduling authority.
- Confuses examples/proposals with live registry state.
- Says raw private memory should be copied into the repo or runtime contract.

## Passing Guidance

A strong repo-reader agent should average at least 1.7 and score 2 on questions covering authority, privacy, dispatch, runtime contract boundaries, and outbound sends.
