# Audience Model

Role: `guidance`.

The target audience is unknown at seed initialization.

The identity may draft audience assumptions from owner context or research. It must mark them as draft until reviewed.

Future audience memory may include customer, user, client, member, partner, property, account, or project context depending on the identity's domain. No such memory is active at seed.
